# Boxing

مدير إشارات مرجعية هرمي على لوحة لا نهائية، بتصميم بيج بسيط وأنيق.

يحول Boxing صفحة علامة التبويب الجديدة في متصفحك إلى مساحة عمل بصرية للإشارات المرجعية. بدلاً من المجلدات التقليدية، نظّم إشاراتك المرجعية في مربعات معنونة على لوحة لا نهائية — اسحب واربط وضمّن بحرية لتناسب طريقة تفكيرك. تماماً مثل لوحة Obsidian مخصصة لإدارة الإشارات المرجعية.

## الميزات

**لوحة لا نهائية** : تحريك وتكبير/تصغير بحرية (Ctrl+عجلة الفأرة). أنشئ عدداً غير محدود من المربعات على لوحة واحدة. عبّر عن العلاقات بين المربعات بخطوط ربط بصرية. حدد علاقات الأصل والفرع — تتحرك المربعات الفرعية تلقائياً عند تحريك المربع الأصلي.

**تسلسل هرمي بمستويين** : تحتوي المربعات الكبيرة على مربعات صغيرة، وتحتوي المربعات الصغيرة على الإشارات المرجعية. انقر فوق أي مربع للدخول إلى لوحته الفرعية. يوضح شريط التنقل مسار التصفح الحالي. إمكانية التضمين لأي عمق مطلوب.

**إدارة الإشارات المرجعية** : يحتفظ كل مربع بمجموعته الخاصة من الإشارات المرجعية مع دعم العرض كقائمة أو شبكة. إضافة وتعديل وحذف بكل سهولة وبساطة. فتح الروابط في علامة التبويب الحالية أو علامة تبويب جديدة (قابل للتخصيص). إعادة الترتيب بالسحب والإفلات.

**خطوط الربط** : خطوط SVG بصرية تصل بين المربعات. اضغط Alt+نقر على الخط لحذفه (قابل للضبط: نقرة واحدة أو نقرتان). انتقال حركة الأصل إلى الفروع مع حدود مرنة ومضبوطة.

**التصميم والمظهر** : جمالية هادئة وبسيطة باللون البيج / الكريمي. وضع داكن يتوافق تلقائياً مع مظهر النظام. إمكانية ضبط حجم الخط ومستوى التكبير. التبديل بين الزوايا الحادة والمستديرة.

**14 لغة** : en, zh_CN, zh_TW, ja, ko, fr, de, es, pt_BR, ru, ar, hi, th, vi (اكتشاف لغة المتصفح تلقائياً).

## التثبيت

> [!IMPORTANT]
> **يُرجى التثبيت عبر صفحات المتاجر الرسمية** (موصى به). خطوات التثبيت المعتمدة ومعلومات الإصدارات المنشورة متوفرة في [ملف README بالإنجليزية — Install](../../README.md#install).
> تُستخدم إصدارات GitHub Releases فقط كـ **سجل تغييرات موجّه للمستخدمين**: [أحدث إصدار](https://github.com/Xxx91n/boxing/releases/latest).

### Firefox (تثبيت رسمي)

1. افتح [Firefox Browser ADD-ONS — Boxing New Tab](https://addons.mozilla.org/ar/firefox/addon/boxing-newtab/)
2. انقر على **Add to Firefox** واتبع تعليمات المتصفح لإتمام التثبيت

### Edge / Chromium (تثبيت رسمي)

1. افتح [Edge Add-ons — Boxing](https://microsoftedge.microsoft.com/addons/detail/inkgieheaiifkkdmlpggihjplkkgpepi)
2. انقر على **الحصول** / **Get** لإتمام التثبيت (لمتصفحات Chromium، يُرجى استخدام متجر Edge)

### للمطورين: البناء من المصدر

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm ci
npm run build
```

- Chrome/Edge: `chrome://extensions` ← تفعيل وضع المطور ← **تحميل إضافة تم فك حزمتها** ← اختيار `dist/boxing-chrome/`
- Firefox: `about:debugging#/runtime/this-firefox` ← **تحميل إضافة مؤقتة...** ← اختيار `dist/boxing-firefox/manifest.json`

> [!NOTE]
> حزم zip الناتجة عن البناء مخصصة **للرفع إلى المتاجر أو فحص الأخطاء محلياً**، وليست قناة تثبيت رسمية للمستخدمين. للاستخدام العادي، يُرجى استخدام روابط المتاجر أعلاه.
> يتم توقيع الإضافات عبر المتاجر الرسمية؛ ولا يتم توزيع ملفات `.xpi` / `.crx` عبر GitHub Releases في هذا المستودع بعد الآن.

## الاستخدام

- **نقر مزدوج** على مساحة فارغة في اللوحة ← إنشاء مربع جديد
- **سحب** شريط عنوان المربع ← تحريك المربع
- **Ctrl+عجلة الفأرة** ← تكبير/تصغير اللوحة (من 30% إلى 200%)
- **سحب** مساحة فارغة في اللوحة ← تحريك اللوحة (بانوراما)
- **نقر بزر الفأرة الأيمن** ← العودة إلى اللوحة الأصلية
- **نقر** على المربع ← الدخول إلى اللوحة الفرعية
- **سحب** من منتصف حافة المربع ← الربط بمربع آخر
- **Alt+نقر** على خط الربط ← حذف خط الربط
- **النجمة** على المربع ← تعيينه كمربع رئيسي (تتحرك الفروع معه)
- **رمز التثبيت (الدبوس)** ← تثبيت موقع المربع
- **الزر الدائري** أعلى يمين اللوحة ← إلغاء التثبيت والانتقال إلى وضع ملء الشاشة

## التطوير

### المتطلبات الأساسية

- Node.js 24.22.1
- npm

### الإعداد

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm install
npx playwright install firefox chromium
npm run build
```

### البناء

```bash
npm run build     # بناء التطوير → dist/boxing-chrome + dist/boxing-firefox
npm test          # اختبارات Playwright (Chrome + Firefox)
```
