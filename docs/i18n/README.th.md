# Boxing

เครื่องมือจัดการบุ๊กมาร์กแบบผืนผ้าใบอินฟินิตี้ตามลำดับชั้น ในดีไซน์มินิมอลโทนสีเบจ

Boxing เปลี่ยนหน้าแท็บใหม่ของเบราว์เซอร์ให้เป็นพื้นที่ทำงานบุ๊กมาร์กแบบมองเห็นได้ ไม่ต้องจัดเก็บในโฟลเดอร์แบบเดิมๆ อีกต่อไป แต่จัดระเบียบบุ๊กมาร์กในกล่องที่มีป้ายกำกับบนผืนผ้าใบแบบไร้ที่สิ้นสุด — ลาก เชื่อมต่อ และซ้อนกันได้ตามวิธีคิดของคุณ เปรียบเสมือนผืนผ้าใบของ Obsidian สำหรับการจัดการบุ๊กมาร์ก

## คุณสมบัติ

**ผืนผ้าใบอินฟินิตี้** : เลื่อนและซูมได้อย่างอิสระ (Ctrl+ลูกกลิ้งเมาส์) สร้างกล่องได้ไม่จำกัดบนผืนผ้าใบเดียว แสดงความสัมพันธ์ระหว่างกล่องด้วยเส้นเชื่อมโยง กำหนดความสัมพันธ์แบบกล่องแม่-ลูก — เมื่อย้ายกล่องแม่ กล่องลูกจะเคลื่อนที่ตาม

**ลำดับชั้นสองระดับ** : กล่องใหญ่ประกอบด้วยกล่องเล็ก และกล่องเล็กประกอบด้วยบุ๊กมาร์ก คลิกกล่องเพื่อเข้าสู่ผืนผ้าใบย่อย แถบนำทาง (Breadcrumbs) แสดงตำแหน่งปัจจุบัน สามารถซ้อนลึกได้ตามต้องการ

**การจัดการบุ๊กมาร์ก** : แต่ละกล่องมีชุดบุ๊กมาร์กของตัวเอง รองรับทั้งมุมมองแบบรายการและแบบตาราง เพิ่ม แก้ไข และลบได้อย่างง่ายดาย เลือกว่าจะเปิดลิงก์ในแท็บปัจจุบันหรือแท็บใหม่ได้ (กำหนดค่าได้) ลากเพื่อจัดเรียงลำดับ

**เส้นเชื่อมโยง** : เส้น SVG แสดงความสัมพันธ์ระหว่างกล่องอย่างชัดเจน กด Alt+คลิก เพื่อลบเส้นเชื่อมโยง (กำหนดค่าได้: คลิกครั้งเดียวหรือดับเบิลคลิก) การเคลื่อนที่ของกล่องแม่ส่งผลต่อกล่องลูกพร้อมขอบเขตที่ยืดหยุ่น

**ดีไซน์และธีม** : สไตล์มินิมอลโทนสีเบจ/ครีม โหมดมืดปรับตามระบบโดยอัตโนมัติ ปรับขนาดตัวอักษรและอัตราการซูมได้ สลับระหว่างมุมเหลี่ยมและมุมโค้งมนได้

## การติดตั้ง

> [!IMPORTANT]
> **แนะนำให้ติดตั้งผ่านหน้าร้านค้าทางการ** (แนะนำ) ขั้นตอนการติดตั้งอย่างเป็นทางการและเวอร์ชันล่าสุดที่เผยแพร่บนสโตร์สามารถดูได้ที่ [README ภาษาอังกฤษ — Install](../../README.md#install)
> GitHub Releases ใช้เป็นเพียง**บันทึกการเปลี่ยนแปลงสำหรับผู้ใช้ (Changelog)** เท่านั้น: [เวอร์ชันล่าสุด](https://github.com/Xxx91n/boxing/releases/latest)

### Firefox (การติดตั้งทางการ)

1. เปิด [Firefox Browser ADD-ONS — Boxing New Tab](https://addons.mozilla.org/en-US/firefox/addon/boxing-newtab/)
2. คลิก **Add to Firefox** และทำตามคำแนะนำของเบราว์เซอร์เพื่อทำการติดตั้งให้เสร็จสมบูรณ์

### Edge / Chromium (การติดตั้งทางการ)

1. เปิด [Edge Add-ons — Boxing](https://microsoftedge.microsoft.com/addons/detail/inkgieheaiifkkdmlpggihjplkkgpepi)
2. คลิก **รับ** / **Get** เพื่อทำการติดตั้งให้เสร็จสมบูรณ์ (เบราว์เซอร์ตระกูล Chromium โปรดใช้หน้าสโตร์ของ Edge)

### สำหรับนักพัฒนา: บิลด์จากซอร์สโค้ด

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm ci
npm run build
```

- Chrome/Edge: `chrome://extensions` → เปิดโหมดนักพัฒนาซอฟต์แวร์ → **โหลดส่วนขยายที่คลายการบีบอัดแล้ว** → เลือก `dist/boxing-chrome/`
- Firefox: `about:debugging#/runtime/this-firefox` → **โหลดโปรแกรมเสริมชั่วคราว...** → เลือก `dist/boxing-firefox/manifest.json`

> [!NOTE]
> ไฟล์ zip ที่ได้จากการบิลด์มีไว้สำหรับ**การอัปโหลดขึ้นสโตร์หรือการทดสอบในเครื่องเท่านั้น** ไม่ใช่ช่องทางติดตั้งทั่วไปสำหรับผู้ใช้ สำหรับการใช้งานปกติโปรดใช้ลิงก์สโตร์ด้านบน
> การลงนามดิจิทัลจะดำเนินการโดยสโตร์ โดย GitHub Releases ของโปรเจกต์นี้**ไม่มีการแจกจ่าย**ไฟล์ `.xpi` / `.crx` อีกต่อไป

## วิธีใช้งาน

- **ดับเบิลคลิก**บนพื้นที่ว่างของผืนผ้าใบ → สร้างกล่องใหม่
- **ลาก**แถบชื่อเรื่องของกล่อง → ย้ายตำแหน่งกล่อง
- **Ctrl+ลูกกลิ้งเมาส์** → ซูมผืนผ้าใบ (30% ถึง 200%)
- **ลาก**บนพื้นที่ว่างของผืนผ้าใบ → เลื่อนมุมมอง (Pan)
- **คลิกขวา** → กลับสู่ผืนผ้าใบระดับบน
- **คลิก**ที่กล่อง → เข้าสู่ผืนผ้าใบย่อย
- **ลาก**จากกึ่งกลางขอบกล่อง → เชื่อมต่อกับกล่องอื่น
- **Alt+คลิก**ที่เส้นเชื่อมโยง → ลบเส้นเชื่อมโยง
- **เครื่องหมายดาว**บนกล่อง → กำหนดเป็นกล่องแม่ (กล่องลูกจะเคลื่อนที่ตาม)
- **หมุด (Pin)** → ตรึงตำแหน่งกล่อง
- **ปุ่มวงกลม**มุมขวาบนของผืนผ้าใบ → เลิกตรึงและเข้าสู่โหมดเต็มหน้าจอ

## การพัฒนา

### สิ่งที่ต้องเตรียมก่อนเริ่มต้น

- Node.js 24.22.1
- npm

### การตั้งค่า

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm install
npx playwright install firefox chromium
npm run build
```

### การบิลด์

```bash
npm run build     # บิลด์สำหรับการพัฒนา → dist/boxing-chrome + dist/boxing-firefox
npm test          # รันทดสอบ Playwright (Chrome + Firefox)
```

ดูคู่มือการพัฒนาฉบับเต็มได้ที่ [CONTRIBUTING.md](../../CONTRIBUTING.md)
