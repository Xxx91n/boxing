# Boxing

Иерархический органайзер закладок на бесконечном холсте, бежевый минималистичный дизайн.

Boxing превращает новую вкладку в визуальное рабочее пространство для закладок. Вместо плоских папок вы организуете закладки в помеченные блоки на бесконечном холсте — перетаскивайте, соединяйте и вкладывайте их пространственно. Представьте холст Obsidian, встретившийся с закладками.

## Возможности

**Бесконечный холст** — Свободное панорамирование и масштабирование (Ctrl+колесо). Создавайте неограниченное количество блоков на одном холсте. Соединяйте блоки линиями для отображения связей. Устанавливайте отношения родитель-потомок — двигаете родителя, потомки следуют.

**Двухуровневая иерархия** — Большие блоки содержат малые блоки, малые блоки содержат закладки. Нажмите на блок, чтобы войти в его под-холст. Хлебные крошки показывают путь. Вкладывайте на любую глубину.

**Управление закладками** — Каждый блок имеет свою коллекцию закладок с видами списка и сетки. Добавление, редактирование, удаление через чистый диалог. Открытие в текущей или новой вкладке (настраиваемо). Перетаскивание для сортировки.

**Соединения** — Визуальные SVG-линии соединений между блоками. Alt+клик по линии для удаления (настраиваемо: одинарный или двойной клик). Распространение движения родитель-потомок с упругим ограничением границ.

**Дизайн и тема** — Бежевая/кремовая минималистичная эстетика. Светлый и тёмный режим с автоматическим определением системы. Регулируемый размер шрифта и масштаб. Переключение квадратных/закруглённых углов.

**14 языков** — en, zh_CN, zh_TW, ja, ko, fr, de, es, pt_BR, ru, ar, hi, th, vi с автоматическим определением языка браузера.

## Установка

> [!IMPORTANT]
> **Устанавливайте с официальных страниц магазинов** (рекомендуется). Этапы установки и актуальная версия в магазинах приведены в [англоязычном README — Install](../../README.md#install).
> GitHub Releases — это **журнал изменений для пользователей**: [последний релиз](https://github.com/Xxx91n/boxing/releases/latest).

### Firefox (официальная установка)

1. Откройте [Firefox Browser ADD-ONS — Boxing New Tab](https://addons.mozilla.org/zh-CN/firefox/addon/boxing-newtab/)
2. Нажмите **Добавить в Firefox** и следуйте подсказкам браузера

### Edge / Chromium (официальная установка)

1. Откройте [Edge Add-ons — Boxing](https://microsoftedge.microsoft.com/addons/detail/inkgieheaiifkkdmlpggihjplkkgpepi)
2. Нажмите **Get** / **Получить**, чтобы установить (в Chromium используйте страницу магазина Edge)

### Разработчикам: сборка из исходников

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm ci
npm run build
```

- Chrome/Edge: `chrome://extensions` → Режим разработчика → **Загрузить распакованное расширение** → выберите `dist/boxing-chrome/`
- Firefox: `about:debugging#/runtime/this-firefox` → **Загрузить временное дополнение** → выберите `dist/boxing-firefox/manifest.json`

> [!NOTE]
> Собранные zip-архивы предназначены **для загрузки в магазины или локальной отладки**, это не официальный канал установки. Используйте ссылки на магазины выше.
> Подпись выполняют магазины; GitHub Releases этого репозитория **больше не** распространяют `.xpi` / `.crx`.

## Использование

- **Двойной клик** по пустому холсту → создать новый блок
- **Перетащить** заголовок блока → переместить блок
- **Ctrl+колесо** → масштаб холста (от 30% до 200%)
- **Перетащить** пустой холст → панорамирование
- **Правый клик** → вернуться на родительский уровень холста
- **Клик** по блоку → войти в под-холст
- **Перетащить** от середины края блока → соединить с другим блоком
- **Alt+клик** по линии соединения → удалить
- **Звезда** на блоке → отметить как родитель (потомки двигаются вместе)
- **Булавка** → заблокировать позицию блока
- **Кнопка-круг** вверху справа холста → открепить заголовок для полноэкранного режима

## Конфиденциальность

- Все данные остаются в `chrome.storage.local` — ничего не покидает ваше устройство, кроме перечисленных ниже исходящих запросов или настроенного вами опционального облачного резервного копирования
- Исходящий трафик ограничен запросами favicon (сторонние сервисы значков и прямые запросы `favicon.ico`), анонимной проверкой версии через GitHub Releases API и опциональным резервным копированием WebDAV / GitHub Gist
- URL-адреса WebDAV по умолчанию должны быть публичными HTTPS-узлами — частные и локальные имена хостов отклоняются (проверяется только имя хоста, без DNS-резолва); явная опция в Настройки → Синхронизация смягчает только этот отказ для самостоятельно размещённых LAN-серверов, HTTPS остаётся обязательным; правила и обоснование в [политике конфиденциальности](../../docs/privacy-policy.md)
- Учётные данные синхронизации хранятся в обфусцированной обёртке (без шифрования пользовательским ключом); вручную экспортированные файлы резервных копий можно дополнительно запечатать парольной фразой — подробности в [политике конфиденциальности](../../docs/privacy-policy.md)
- Никакой аналитики, никакого отслеживания, сторонний код не выполняется
- Полная политика конфиденциальности: [docs/privacy-policy.md](../../docs/privacy-policy.md)

## Разработка

### Требования

- Node.js 24.22.1
- npm

### Настройка

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm install
npx playwright install firefox chromium
npm run build
```

### Сборка

```bash
npm run build     # Сборка для разработки → dist/boxing-chrome + dist/boxing-firefox
npm test          # Тесты Playwright (Chrome + Firefox)
```
