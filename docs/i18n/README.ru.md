# Boxing

Иерархический менеджер закладок на бесконечном холсте, бежевый минималистичный дизайн.

Boxing превращает новую вкладку браузера в визуальное рабочее пространство для закладок. Вместо обычных плоских папок организуйте закладки в подписанных карточках-боксах на бесконечном холсте — перетаскивайте, соединяйте и вкладывайте их так, как устроено ваше мышление. Это как холст Obsidian, созданный для работы с закладками.

## Возможности

**Бесконечный холст** : Свободное перемещение и масштабирование (Ctrl+колесо мыши). Создавайте неограниченное количество боксов на одном холсте. Отображайте связи между боксами соединительными линиями. Настраивайте отношения родитель-потомок — дочерние боксы перемещаются вслед за родительским.

**Двухуровневая иерархия** : Большие боксы содержат малые боксы, а малые боксы содержат закладки. Нажмите на бокс, чтобы открыть его вложенный холст. Строка навигации («хлебные крошки») показывает путь. Вложенность возможна на любую глубину.

**Управление закладками** : У каждого бокса свой набор закладок с поддержкой отображения списком или сеткой. Простое добавление, редактирование и удаление. Открытие ссылок в текущей или новой вкладке (настраивается). Сортировка перетаскиванием.

**Линии связей** : Наглядные SVG-линии между боксами. Alt+клик по линии для удаления (настраивается: одиночный или двойной клик). Перемещение дочерних элементов вслед за родительскими с эластичным ограничением границ.

**Дизайн и темы** : Минималистичный бежево-кремовый стиль. Темная тема с автоматическим следованием системе. Настройка размера шрифта и масштаба. Переключение между прямыми и скругленными углами.

**14 языков** : en, zh_CN, zh_TW, ja, ko, fr, de, es, pt_BR, ru, ar, hi, th, vi (автоматическое определение языка браузера).

## Установка

> [!IMPORTANT]
> **Рекомендуется установка через официальные магазины расширений** (рекомендуется). Официальные инструкции и информация о версиях в магазинах доступны в [английской версии README — Install](../../README.md#install).
> Раздел GitHub Releases используется исключительно как **список изменений для пользователей**: [Последняя версия](https://github.com/Xxx91n/boxing/releases/latest).

### Firefox (официальная установка)

1. Откройте страницу [Firefox Browser ADD-ONS — Boxing New Tab](https://addons.mozilla.org/ru/firefox/addon/boxing-newtab/)
2. Нажмите **Add to Firefox** и подтвердите установку в браузере

### Edge / Chromium (официальная установка)

1. Откройте [Edge Add-ons — Boxing](https://microsoftedge.microsoft.com/addons/detail/inkgieheaiifkkdmlpggihjplkkgpepi)
2. Нажмите **Получить** / **Get** для завершения установки (для браузеров на базе Chromium используйте страницу магазина Edge)

### Для разработчиков: сборка из исходного кода

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm ci
npm run build
```

- Chrome/Edge: `chrome://extensions` → включить «Режим разработчика» → **Загрузить распакованное расширение** → выбрать `dist/boxing-chrome/`
- Firefox: `about:debugging#/runtime/this-firefox` → **Загрузить временное дополнение...** → выбрать `dist/boxing-firefox/manifest.json`

> [!NOTE]
> Сборка в архив zip предназначена для **отправки в магазины или локальной отладки**, а не в качестве официального канала установки для пользователей. Для обычной установки перейдите по ссылкам на магазины выше.
> Подписание выполняется магазинами; в релизах GitHub файлы `.xpi` / `.crx` **больше не распространяются**.

## Использование

- **Двойной клик** по пустому месту холста → Создать новый бокс
- **Перетаскивание** заголовка бокса → Переместить бокс
- **Ctrl+колесо мыши** → Масштабирование холста (от 30% до 200%)
- **Перетаскивание** за пустое место холста → Сдвиг холста (панорамирование)
- **Правый клик** → Вернуться в родительский холст
- **Клик** по боксу → Войти во вложенный холст
- **Перетаскивание** от середины края бокса → Соединить с другим боксом
- **Alt+клик** по линии связи → Удалить линию
- **Звездочка** на боксе → Сделать родительским (дочерние боксы перемещаются вместе с ним)
- **Кнопка-булавка (Pin)** → Зафиксировать положение бокса
- **Круглая кнопка** в правом верхнем углу холста → Снять фиксацию и перейти в полноэкранный режим

## Разработка

### Требования

- Node.js 24.22.1
- npm

### Настройка

```bash
git clone https://github.com/Xxx91n/boxing.git
cd boxing
npm install
npx playwright install firefox chromium
npm run build
```

### Сборка

```bash
npm run build     # Сборка для разработки → dist/boxing-chrome + dist/boxing-firefox
npm test          # Тесты Playwright (Chrome + Firefox)
```

Подробное руководство разработчика см. в [CONTRIBUTING.md](../../CONTRIBUTING.md).
