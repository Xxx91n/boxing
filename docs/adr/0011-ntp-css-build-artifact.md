# ADR-0011: ntp.css Build Artifact — Gitignore + Validator Refactor

## Date
2026-08-10

## Status
Accepted — implemented.

## Context
ntp/ntp.css is a build artifact generated by build.mjs from 4 source files (base.css + settings.css + onboarding.css + conn.css). It was previously committed to git AND tracked, causing confusion: developers might accidentally edit the artifact instead of source files. The A8 dual-write validator read ntp.css instead of the source files, meaning validation could only run after the build.

PWM research (gpt56_terra) confirmed: enterprise standard for browser extensions (Vue DevTools, React DevTools, Ghostery) is to gitignore build artifacts and have validators read source files.

## Decision
1. Add ntp/ntp.css to .gitignore.
2. git rm --cached ntp/ntp.css to untrack it from git.
3. Refactor build.mjs A8 validator to concatenate and read the 4 source files directly, not ntp.css.
4. Document in css-dual-write-convention.md that ntp.css is a build artifact.
5. Update AGENTS.md to note ntp.css is generated, not a direct editing target.

## Consequences
- ntp.css is regenerated on every build; never committed.
- Validator runs independently of the build step.
- Source files (base.css, settings.css, onboarding.css, conn.css) are the only CSS files developers should edit.
- dist/ still contains ntp.css (generated during build, stripped from source files).
