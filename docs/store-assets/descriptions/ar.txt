يحوّل Boxing تبويبك الجديد إلى مساحة عمل بصرية بلوحة لا نهائية للإشارات المرجعية.
بدل المجلدات المسطحة، رتّب الروابط في صناديق بعناوين: اسحب، وصِل، وعشّق حسب طريقة تفكيرك.

الميزات

لوحة لا نهائية
• تكبير وإزاحة بـ Ctrl+عجلة الفأرة
• صناديق بلا حدود على لوحة واحدة
• وصّل الصناديق بخطوط لإظهار العلاقات
• حركة أب-ابن: حرّك الأب ويتبعه الأبناء
• نقر مزدوج على الفراغ لإنشاء صندوق
• زر الفأرة الأيمن للعودة إلى اللوحة الأعلى

إدارة الإشارات المرجعية
• لكل صندوق مجموعة مستقلة
• عرض قائمة وشبكة
• إضافة وتعديل وحذف عبر حوار بسيط
• عنوان ورابط ووصف مخصص
• اسحب لإعادة الترتيب داخل الصندوق
• فتح في التبويب الحالي أو تبويب جديد (قابل للإعداد)

تنظيم هرمي
• يمكن للصناديق احتواء لوحة فرعية — انقر للدخول
• تنقّل بمسارات توضح مسارك
• تعشيق بلا حدود؛ كل مستوى مستقل

التصميم والسمة
• مظهر بيج/كريمي بسيط وهادئ
• وضع فاتح وداكن (يتبع النظام)
• حجم الخط والتكبير قابلان للتعديل
• خطوط ربط SVG ناعمة
• زوايا دائرية اختيارية

الخصوصية أولاً
• تبقى كل البيانات على جهازك
• نسخ احتياطي WebDAV اختياري إلى خادمك
• نسخ GitHub Gist اختياري
• بلا تحليلات أو تتبّع أو خدمات طرف ثالث
• مفتوح المصدر (Apache-2.0)

الاتصالات
• احذف الخيط بـ Alt+نقر (يمكن الإعداد لنقر أو نقر مزدوج)
• العلاقات تظهر كخطوط مرئية

الأذونات

storage — حفظ الإشارات والتخطيط والإعدادات محليًا
tabs — فتح الإشارات في تبويب جديد حسب إعدادك
وصول مضيف اختياري (Chrome) / وصول مضيف (Firefox) — لنسخ WebDAV الخاص بك فقط

لا نطلب سجل التصفح أو التنزيلات أو الحافظة أو بيانات نشاط أخرى.

حالات الاستخدام

• مشاريع بحثية — لوحة لكل مشروع وصناديق لكل موضوع
• تنظيم مجموعات إشارات مرجعية بصريًا
• خرائط معرفة بروابط مكانية
• وصول سريع للروابط المتكررة في كل تبويب جديد
