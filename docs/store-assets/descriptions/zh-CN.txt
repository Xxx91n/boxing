Boxing 将新标签页变成可视化、可无限延展的书签画布工作区。
不再依赖扁平文件夹：把链接整理进带标签的盒子，拖动、连线、嵌套，按你的思路组织。

功能

无限画布
• Ctrl+滚轮自由缩放与平移
• 单张画布可创建无限个盒子
• 用连线表达盒子之间的关系
• 父子层级：移动父盒子时子盒子跟随
• 双击空白处新建盒子
• 右键返回上级画布

书签管理
• 每个盒子拥有独立的书签集合
• 列表视图与网格视图
• 简洁对话框添加、编辑、删除书签
• 可自定义标题、URL 与描述
• 盒内拖拽排序
• 可配置在当前页或新标签页打开

层级组织
• 盒子可包含子画布，点击进入
• 面包屑导航显示层级路径
• 嵌套深度不限，每一层相互独立

设计与主题
• 米色/奶油色极简风格，安静专注
• 浅色/深色模式（可跟随系统）
• 可调字号与缩放
• 平滑 SVG 连线
• 可选圆角

隐私优先
• 数据全部保存在本机
• 可选 WebDAV 备份到你自己的服务器
• 可选 GitHub Gist 备份
• 无统计、无追踪、无第三方服务
• 开源（Apache-2.0）

连线
• Alt+单击删除连线（也可配置为单击或双击）
• 关系以可视连线呈现

权限说明

storage — 在本地保存书签、布局与设置
tabs — 按你的配置在新标签页打开书签
可选主机访问（Chrome）/ 主机访问（Firefox）— 仅在你配置自己的 WebDAV 备份时使用

我们不请求浏览历史、下载、剪贴板或其他活动数据。

适用场景

• 科研项目：每个项目一张画布，每个主题一个盒子
• 多年收藏的可视化整理
• 知识关联与空间化地图
• 把常用链接钉在新标签页作为快捷入口

技术信息

纯原生 JavaScript，无框架、无打包器。
支持 Chrome、Edge、Firefox 及其他 Chromium 浏览器。
Manifest V3。
