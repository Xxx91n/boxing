Boxing 將新分頁畫面變成可視覺化、可無限延展的書籤畫布工作區。
不再依賴扁平資料夾：把連結整理進有標籤的盒子，拖曳、連線、巢狀，依你的思路組織。

功能

無限畫布
• Ctrl+滾輪自由縮放與平移
• 單張畫布可建立無限個盒子
• 用連線表達盒子之間的關係
• 父子層級：移動父盒子時子盒子跟隨
• 雙擊空白處新增盒子
• 右鍵返回上層畫布

書籤管理
• 每個盒子擁有獨立的書籤集合
• 清單檢視與格狀檢視
• 簡潔對話框新增、編輯、刪除書籤
• 可自訂標題、URL 與描述
• 盒內拖曳排序
• 可設定在目前分頁或新分頁開啟

階層組織
• 盒子可包含子畫布，點擊進入
• 麵包屑導覽顯示階層路徑
• 巢狀深度不限，每一層相互獨立

設計與主題
• 米色/奶油色極簡風格，安靜專注
• 淺色/深色模式（可跟隨系統）
• 可調字級與縮放
• 平滑 SVG 連線
• 可選圓角

隱私優先
• 資料全部保存在本機
• 可選 WebDAV 備份到你自己的伺服器
• 可選 GitHub Gist 備份
• 無統計、無追蹤、無第三方服務
• 開源（Apache-2.0）

連線
• Alt+單擊刪除連線（也可設定為單擊或雙擊）
• 關係以視覺連線呈現

權限說明

storage — 在本機儲存書籤、版面與設定
tabs — 依你的設定在新分頁開啟書籤
可選主機存取（Chrome）/ 主機存取（Firefox）— 僅在你設定自己的 WebDAV 備份時使用

我們不要求瀏覽紀錄、下載、剪貼簿或其他活動資料。

適用情境

• 研究專案：每個專案一張畫布，每個主題一個盒子
• 多年收藏的視覺化整理
• 知識關聯與空間化地圖
• 把常用連結釘在新分頁作為快速入口

技術資訊

支援 Chrome、Edge、Firefox 及其他 Chromium 瀏覽器。
