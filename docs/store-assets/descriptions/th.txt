Boxing จะเปลี่ยนแท็บใหม่ของคุณให้เป็นพื้นที่ทำงานภาพบนผืนผ้าใบที่ไม่มีที่สิ้นสุดสำหรับบุ๊กมาร์ก
แทนโฟลเดอร์แบบแบน จัดลิงก์ในกล่องที่มีป้ายกำกับ ลาก เชื่อม และซ้อน ตามวิธีคิดของคุณ

ฟีเจอร์

ผืนผ้าใบไม่จำกัด
• เลื่อนและซูมด้วย Ctrl+เลื่อนล้อ
• สร้างกล่องได้ไม่จำกัดบนผืนผ้าใบเดียว
• เชื่อมกล่องด้วยเส้นเพื่อแสดงความสัมพันธ์
• เคลื่อนที่แบบพ่อลูก: ย้ายพ่อ ลูกตาม
• ดับเบิลคลิกที่ว่างเพื่อสร้างกล่อง
• คลิกขวาเพื่อกลับไปผืนผ้าใบระดับบน

จัดการบุ๊กมาร์ก
• แต่ละกล่องมีชุดบุ๊กมาร์กของตัวเอง
• มุมมองรายการและตาราง
• เพิ่ม แก้ไข ลบในกล่องโต้ตอบที่อ่านง่าย
• กำหนดชื่อ URL และคำอธิบายเอง
• ลากเพื่อจัดลำดับในกล่อง
• เปิดในแท็บปัจจุบันหรือแท็บใหม่ (ตั้งค่าได้)

ลำดับชั้น
• กล่องสามารถมีผืนผ้าใบย่อย — คลิกเพื่อเข้า
• แถบนำทางแสดงเส้นทางของคุณ
• ซ้อนได้ลึกตามต้องการ แต่ละชั้นอิสระ

ดีไซน์และธีม
• โทนเบจ/ครีมมินิมอล สงบ
• โหมดสว่าง/มืด (ตามระบบ)
• ปรับขนาดตัวอักษรและซูมได้
• เส้นเชื่อม SVG นุ่มนวล
• มุมมนเป็นตัวเลือก

ความเป็นส่วนตัวก่อน
• ข้อมูลทั้งหมดอยู่บนอุปกรณ์ของคุณ
• สำรอง WebDAV ไปยังเซิร์ฟเวอร์ของคุณเอง (ไม่บังคับ)
• สำรอง GitHub Gist (ไม่บังคับ)
• ไม่มีการวิเคราะห์ ติดตาม หรือบริการบุคคลที่สาม
• โอเพ่นซอร์ส (Apache-2.0)

การเชื่อมต่อ
• ลบเส้นด้วย Alt+คลิก (ตั้งเป็นคลิกหรือดับเบิลคลิกได้)
• ความสัมพันธ์แสดงเป็นเส้นที่มองเห็น

สิทธิ์

storage — เก็บบุ๊กมาร์ก เลย์เอาต์ และการตั้งค่าไว้ในเครื่อง
tabs — เปิดบุ๊กมาร์กในแท็บใหม่ตามที่คุณตั้งค่า
การเข้าถึงโฮสต์แบบไม่บังคับ (Chrome) / การเข้าถึงโฮสต์ (Firefox) — เฉพาะสำรอง WebDAV ของคุณเท่านั้น

เราไม่ขอประวัติการเข้าชม การดาวน์โหลด คลิปบอร์ด หรือข้อมูลกิจกรรมอื่น

กรณีใช้งาน

• โครงการวิจัย — หนึ่งผืนผ้าใบต่อโครงการ กล่องต่อหัวข้อ
• จัดระเบียบบุ๊กมาร์กสะสมหลายปีให้เห็นภาพ
• แผนที่ความรู้ด้วยลิงก์เชิงพื้นที่
• เข้าถึงลิงก์บ่อยจากทุกแท็บใหม่
