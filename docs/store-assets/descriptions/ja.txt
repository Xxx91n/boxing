Boxing は、新しいタブをブックマーク用のビジュアルな無限キャンバスワークスペースに変えます。
フラットなフォルダではなく、ラベル付きボックスにリンクを整理。ドラッグ、接続、ネストで自分の考え方に合わせて並べられます。

機能

無限キャンバス
• Ctrl+スクロールでパンとズーム
• 1 枚のキャンバスにボックスを無制限に作成
• ボックス間の関係を線で表現
• 親子関係：親を動かすと子も追従
• 空白をダブルクリックしてボックス作成
• 右クリックで親キャンバスへ戻る

ブックマーク管理
• 各ボックスに独立したブックマーク集合
• リスト表示とグリッド表示
• シンプルなダイアログで追加・編集・削除
• タイトル・URL・説明をカスタマイズ
• ボックス内でドラッグ並べ替え
• 現在のタブまたは新しいタブで開く（設定可）

階層整理
• ボックスにサブキャンバスを含められる（クリックで入る）
• パンくずナビで階層の道筋を表示
• 深さ制限なし。各レベルは独立

デザインとテーマ
• 落ち着いたベージュ／クリームのミニマルな見た目
• ライト／ダークモード（システムに追従）
• 文字サイズとズームを調整可能
• なめらかな SVG 接続線
• 角丸スタイルをオプションで選択

プライバシー優先
• データはすべて端末内に保存
• 自分のサーバーへの WebDAV バックアップ（任意）
• GitHub Gist バックアップ（任意）
• 解析・追跡・サードパーティなし
• オープンソース（Apache-2.0）

接続
• Alt+クリックで線を削除（クリック／ダブルクリックにも変更可）
• 関係を視覚的な線で表示

権限について

storage — ブックマーク・レイアウト・設定を端末に保存
tabs — 設定に応じて新しいタブでブックマークを開く
任意のホストアクセス（Chrome）/ ホストアクセス（Firefox）— 自分の WebDAV バックアップを設定した場合のみ使用

閲覧履歴、ダウンロード、クリップボードなどの操作データは要求しません。

利用シーン

• リサーチ案件：案件ごとにキャンバス、トピックごとにボックス
• 長年のブックマークを視覚的に整理
• 空間的なリンクで知識をつなぐ
• よく使うリンクを新しいタブに置いてクイックアクセス

Chrome、Edge、Firefox、その他の Chromium 系で動作。
