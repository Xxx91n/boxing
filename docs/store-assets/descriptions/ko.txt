Boxing은 새 탭을 북마크용 시각적 무한 캔버스 작업 공간으로 바꿉니다.
납작한 폴더 대신 라벨이 붙은 상자에 링크를 정리하고, 끌고, 연결하고, 중첩해 생각하는 방식에 맞게 배치하세요.

기능

무한 캔버스
• Ctrl+스크롤로 이동 및 확대/축소
• 한 캔버스에 상자를 원하는 만큼 생성
• 선으로 상자 관계 표현
• 부모-자식 이동: 부모를 옮기면 자식도 따라옴
• 빈 곳을 두 번 클릭해 상자 만들기
• 오른쪽 클릭으로 상위 캔버스로 돌아가기

북마크 관리
• 각 상자에 독립된 북마크 모음
• 목록 보기와 격자 보기
• 간결한 대화 상자로 추가·편집·삭제
• 제목, URL, 설명 사용자 지정
• 상자 안에서 끌어서 순서 변경
• 현재 탭 또는 새 탭에서 열기(구성 가능)

계층 구조
• 상자에 하위 캔버스 포함 가능(클릭해 들어감)
• 경로를 보여 주는 브레드크럼 탐색
• 깊이 제한 없음, 각 층은 독립적

디자인 및 테마
• 차분한 베이지/크림 미니멀 룩
• 라이트/다크 모드(시스템 따라가기)
• 글꼴 크기와 확대/축소 조절
• 부드러운 SVG 연결선
• 둥근 모서리 옵션

프라이버시 우선
• 모든 데이터는 기기에 저장
• 원하는 경우 사용자 서버로 WebDAV 백업
• 원하는 경우 GitHub Gist 백업
• 분석·추적·서드파티 없음
• 오픈 소스(Apache-2.0)

연결
• Alt+클릭으로 선 삭제(클릭/더블클릭으로도 변경 가능)
• 관계를 시각적 선으로 표시

권한 설명

storage — 북마크·레이아웃·설정을 로컬에 저장
tabs — 설정에 따라 새 탭에서 북마크 열기
선택적 호스트 액세스(Chrome)/호스트 액세스(Firefox) — 사용자 WebDAV 밐업을 설정할 때만 사용

검색 기록, 다운로드, 클립보드 등 활동 데이터를 요구하지 않습니다.

사용 사례

• 연구 프로젝트: 프로젝트마다 캔버스, 주제마다 상자
• 오래 모은 북마크를 시각적으로 정리
• 공간적 연결로 지식 지도 만들기
• 자주 쓰는 링크를 새 탭에 고정해 빠르게 열기

Chrome, Edge, Firefox 및 기타 Chromium 브라우저에서 동작.
