Boxing 2026.9.12

一个更稳、更跟手的书签新标签页：无限画布 + 分层盒子，把书签按你的思路排开。

## 这版你能感觉到的变化

### 新增
- **新标签页零闪现** — 打开新标签的首帧就已是你的主题与明暗，不再闪一下默认米色
- **冲突副本可浏览** — 设置 → 数据区可列出冲突归档，并导出单条 JSON
- **WebDAV 私网开关** — 默认仍拒绝内网/本机地址；你可在设置里显式允许自己的 NAS/自建服务
- **搜索防抖** — 画布搜索不再每个键都重查

### 改进
- 备份凭据改为**每安装随机密钥**包装（静态混淆级，不是口令级加密；说明见隐私页）
- 数据写入路径更严：布局写入统一走存储门面，降低跨标签/同步踩坑
- 弹窗主按钮使用设计系统强调色
- 文档与发行说明改为**面向用户**；正式安装引导到商店

### 修复
- 关闭标签页过快时，刚删除的连线或刚播种的盒子可能未落盘
- 跨标签同步 / 快照相关一致性问题
- 界面版本号跟随 manifest 日历版本
