# Boxing 2026.9.15

A stability closeout: cross-tab star-sync fix, dark-mode contrast to WCAG targets, and WebDAV layout merge upgraded to three-way.

## What you will notice

### Fixed
- Cross-tab star / parent sync no longer flakes in multi-window use.
- Dark empty-state “add bookmark” controls meet contrast targets (text and border).
- WebDAV concurrent edits merge by box id — both sides keep their new small boxes; conflicts become browsable copies instead of silent loss.
- Boot theme: if init fails early, the temporary content mask always clears (no permanent blank page).

### Improved
- Search input debounce (fewer full rebuilds while typing).
- Settings: WebDAV private-host opt-in documented; credentials are per-install.
- Version strings all read the same CalVer source (2026.9.15).

### Internal
- New CI guards: calver surface, onboarding dismiss, locale README claims, contrast pairs, docs links, waiver revocation criteria.
- Release zip no longer ships `.scratch` working notes.
