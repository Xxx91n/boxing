Boxing 2026.10.17

四大核心改进与稳定性强化：自动备份本地模式收敛静默快照、版本检查直连权威发布源、设计系统 Token 规范化与对比度修复、以及快照总数硬上限 30 条。

## 这版你能感觉到的变化

### 新增与优化
- **自动备份本地模式收敛静默快照** — 在本地模式下，定时备份与启动补跑严格收敛为内部快照静默保存（snapshot-by-default），彻底消除每次打开新标签页侵入式弹出文件下载对话框的问题；同时保留设置页中“立即备份”显式导出功能。
- **版本检查直连权威发布源** — “关于”页新版本检查改为直连 GitHub Releases API 作为权威第一数据源，同时保留 Pages 镜像降级容灾；新增“检查更新”按钮支持强制刷新，检测到更新时展示低侵入提示与链接。
- **快照 30 条硬上限防膨胀** — 新增绝对数量硬上限 MAX_SNAPSHOT_COUNT = 30；超过上限时自动按 GFS 历史分层规则淘汰最旧快照并物理删除散列键，杜绝存储膨胀与孤儿键残留，同时无条件保证最新 10 条快照安全底线。

### 修复
- **设计系统 Token 规范化与对比度修复** — 修复规则按钮（上移/下移/删除）在暗色模式下的可读性与无障碍对比度（满足 WCAG SC 1.4.3 及 SC 1.4.11）；补齐 --color-danger、--color-hover 与 --radius-sm 语义 Token，彻底消除删除键未定义回退与圆角丢失。

### 内部
- 架构决策落地：ADR-0024（自动备份本地模式收敛与快照 30 条硬上限）。
- 扩展对比度守卫与全平台自动化测试去空转验证。

## English

Boxing 2026.10.17

Four core improvements and resilience upgrades: quiet internal auto-backups in local mode, authoritative direct version check against GitHub Releases, design token normalization with WCAG contrast fixes, and a hard 30-snapshot ceiling.

## What you will notice

### New & Improved
- **Quiet auto-backups in local mode** — Scheduled and catch-up backups now save silent internal snapshots by default without intrusive file download prompts every time a new tab opens. Explicit "Backup Now" remains available for on-demand JSON exports.
- **Direct authoritative version check** — Update checks in the About tab now query the GitHub Releases API directly as the primary authority with fallback to the Pages mirror. An explicit "Check for updates" button enables force-refreshing the 2-hour cache.
- **Hard 30-snapshot ceiling** — Introduced MAX_SNAPSHOT_COUNT = 30 to prevent unbounded storage growth. Snapshots beyond 30 are pruned FIFO under GFS tiering with immediate physical key deletion, while keeping the 10 newest snapshots unconditionally safe.

### Fixed
- **Design token normalization & contrast** — Normalized rule action buttons (move up, move down, delete) to semantic design tokens (--color-danger, --color-hover, --radius-sm), restoring delete danger coloring, 3px border-radius, and passing WCAG SC 1.4.3 / 1.4.11 contrast requirements in both light and dark themes.

### Internal
- Architecture decision: ADR-0024 (local auto-backup convergence & snapshot cap).
- Upgraded contrast-guard and non-idle snapshot cap test verification.
