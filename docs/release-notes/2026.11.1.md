Boxing 2026.11.1

安全收口发布：发布流程整体加固，四项运行时防护落地，隐私声明与实际出网行为对齐。本轮不新增功能，重点是让扩展在构建、同步与浏览三个环节都更稳、更可预期。

## 这版你能感觉到的变化

### 发布与更新
- **发布流程加固** — 构建与发布链整体收口：版本输入经过严格校验、依赖与 CI 组件全部锁定到不可变版本、发布步骤只使用已审计的锁文件工具，更新与构建更安全、可复现。
- **Node 版本线统一** — 开发与 CI 环境统一到 Node 24.22.1 修复线，工具链行为与声明保持一致。

### 同步与凭据
- **修改同步设置不再误清已保存凭据** — 调整 WebDAV 地址或用户名时，已保存的密码与令牌保持不变；只有对应字段真正变化时才会更新，避免一次普通编辑导致下次同步失败。

### 书签与浏览
- **书签打开统一走安全校验** — 从搜索结果打开书签与普通书签行使用同一套 URL 归一化校验，只允许 http(s) 目标被导航。

### WebDAV 同步
- **传输链路加固** — WebDAV 同步在所有路径上拒绝透明重定向，并限制响应读取上限，异常或恶意服务器无法把任意大的数据塞进扩展进程。

### 自动标题规则
- **规则边界保护** — 自动标题规则增加长度与通配符数量上限，非法编码路径不再导致异常，病态规则不会冻结新标签页。

### 内部
- 隐私声明与实际出网行为对齐（favicon 取源、版本检查、站点探测均已在政策中披露）。
- 仓库根清理与忽略规则落地；审计报告不入库，证据按 finding ID 索引。
- 全部 12 个 guard 与既有安全 spec 保持全绿。

## English

Boxing 2026.11.1

Security hardening release: hardened release pipeline, four runtime protections, and privacy disclosures aligned with actual outbound behavior. No new features — this release makes building, syncing, and browsing more stable and predictable.

## What you will notice

### Build & updates
- **Hardened release pipeline** — Version inputs are strictly validated, CI components are pinned to immutable versions, and release steps only use audited lockfile tools for safer, reproducible builds.
- **Unified Node line** — Development and CI now run Node 24.22.1 fixed line, matching declared toolchain behavior.

### Sync & credentials
- **Editing sync settings no longer wipes saved credentials** — Changing your WebDAV address or username keeps saved passwords and tokens intact; envelopes are only rewritten when the corresponding field genuinely changes.

### Bookmarks & browsing
- **Unified safe bookmark navigation** — Opening bookmarks from search results goes through the same URL normalization as regular bookmark rows; only http(s) targets are navigated.

### WebDAV sync
- **Hardened transfer path** — WebDAV sync refuses transparent redirects on every path and caps response reads, so an abnormal or malicious server cannot push unbounded data into the extension process.

### Auto-title rules
- **Rule boundary protection** — Auto-title rules are bounded in length and wildcard count, malformed encodings no longer throw, and pathological rules cannot freeze the new-tab page.

### Internal
- Privacy statement aligned with actual outbound behavior (favicon sources, update checks, site probing all disclosed).
- Repository-root cleanup and ignore rules landed; audit reports stay out of the repo, evidence indexed by finding ID.
- All 12 guards and existing security specs remain green.
