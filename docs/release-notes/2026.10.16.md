Boxing 2026.10.16

五项核心功能与稳定性修复：Favicon 图标恢复显示、自动备份 SW 闹钟枢纽与补跑、标题全选与光标定位稳定性、About 页新版本静默检查、URL 规则自动填充书签标题。

## 这版你能感觉到的变化

### 新增与优化
- **URL 规则自动填充书签标题** — 添加与编辑书签时，根据 URL 结构（8 类预设规则 + match-pattern 匹配器 + 常见多段域名解析）自动推导并填充标题。设置 General 页支持开关与规则自定义。用户手动修改标题后受到严格保护，不会被覆盖。
- **About 页新版本静默检查** — 打开“关于”页面时自动检查是否有新版本，结果静默缓存 24 小时；有新版本时优雅展示更新提示与链接，不弹出横幅骚扰。
- **自动备份稳定补跑机制** — 引入 Service Worker 闹钟枢纽与 autoBackupDue 补跑标记；解决因新标签页关闭导致定时备份丢失的问题，重启扩展或重新打开新标签页时自动补跑。

### 修复
- **Favicon 首次进入小盒页恢复显示** — 修复首次打开小盒子页面时由于空 src 引发错误导致图标 display: none 滞留隐藏的问题。
- **标题首击全选与二击落光标修复** — 修复大盒、小盒与内层面包屑标题在首击全选时的时序竞态；第二次点击在对应位置精准放置原生光标，方向键可折叠选区。

### 内部
- 新增 ADR-0022（自动备份 = SW 闹钟枢纽 + NTP 执行 + 补跑检查）与 ADR-0023（URL 规则自动填标题规则引擎）。
- 14 种语言国际化字典完整覆盖。

## English

Boxing 2026.10.16

Five core improvements and stability fixes: favicon display on first entry, auto-backup service worker alarm hub with catch-up, robust title select-all and caret placement, quiet version update checking in About tab, and URL structure-derived bookmark auto-title.

## What you will notice

### New & Improved
- **URL auto-title rule engine** — When adding or editing bookmarks, titles are derived from the URL structure using 8 preset rules, Chrome-style match-patterns, and multi-part public suffix parsing. Fully customizable in Settings > General. Manually edited titles are guarded against being overwritten.
- **About tab version check** — Quietly checks for newer releases when opening the About tab, caching results for 24 hours. Displays a non-intrusive link when a new version is available.
- **Reliable auto-backup with catch-up** — Service Worker alarm hub records due status; if scheduled backups occur while NTP is closed, the backup automatically catches up upon opening a new tab.

### Fixed
- **Favicon visibility on first small-box entry** — Fixed an issue where empty src initialization triggered an error event that permanently hid the favicon via display: none.
- **Title select-all and caret positioning** — Solved timing races across large, small, and breadcrumb box titles. The first click reliably selects all text, while a subsequent click places the caret natively.

### Internal
- Architecture decisions: ADR-0022 (auto-backup alarm hub + NTP catch-up) and ADR-0023 (URL auto-title rule engine).
- Full 14-locale i18n support.
