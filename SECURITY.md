# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.7.x   | Yes       |
| < 3.7   | No        |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Please report via [GitHub Security Advisories](https://github.com/Xxx91n/boxing/security/advisories/new) (Private Vulnerability Reporting).

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected version
- Suggested fix (if any)

## Response Timeline

- Acknowledgment: within 72 hours
- Initial assessment: within 7 days
- Fix or mitigation: depends on severity, targeted within 30 days

## Scope

Boxing is a client-only browser extension. All data is stored locally. The only outbound network access is user-configured WebDAV or GitHub Gist backup. No analytics, no tracking, no third-party services.
