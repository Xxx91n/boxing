### 5.1 [P-02] DNS 配置（必须在发版前完成！）
> ⚠️ **高危时序提示**：由于新构建产物已包含 `CNAME`，一旦合并发布，GitHub Pages 会立即将 `xxx91n.github.io/boxing/` 301 重定向至 `boxing.xxx91n.com`。如果此时 DNS 未解析，会导致整站不可访问！

1. 登录 **Spaceship** DNS 控制台（域名 `xxx91n.com`）。
2. 添加一条 CNAME 记录：
   - **Host / Name**：`boxing`
   - **Target / Value**：`xxx91n.github.io.`
   - **TTL**：Auto 或 300 / 3600
3. *(推荐)* 前往 GitHub 个人设置 → Pages → Verified domains，添加 `xxx91n.com` 并按提示在 DNS 添加一条 TXT 验证记录（防止子域名劫持）。
4. 在终端验证 DNS 是否生效：
   ```bash
   nslookup boxing.xxx91n.com
   # 预期应解析指向 GitHub Pages 的 IP 集合
   ```
